OpenAI Challenge (5th Teammate)
Use the OpenAI API to build something ambitious, with Codex as your development teammate. Whether Codex helps you ship a focused feature, turn a prototype into a polished product, or coordinate an end-to-end build, show us how it helped you go further than you otherwise could.


Projects will be assessed on:
- What you built with the OpenAI API: how creatively and effectively the API powers the experience.
- How Codex helped you build it: how meaningfully it supported planning, implementation, testing, debugging, or iteration.
- During your demo, show the working product, explain how the OpenAI API is used, and share one concrete way Codex improved your process or outcome. First, second, and third place will go to the strongest projects across both areas.


Check out our documentation on Codex use case examples to get started, and feel free to stop by our booth if you have any questions!
